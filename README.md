# Canvas RPG Kit

A lightweight vanilla JS + HTML5 Canvas RPG prototype and engine foundation built around Tiled maps, Aseprite animations, and a custom scene-graph architecture.

This project is designed as an experimental game toolkit for creating top-down RPG systems without a framework. It emphasizes data-driven content, tile-based gameplay, reusable object logic, and a clean event-driven structure.

## Features

- Tile-based movement and combat
- Top-down 2D world rendering on HTML5 Canvas
- Tiled map support with chunked open-world loading
- Aseprite sprite-sheet and animation pipeline
- Character state machine and combat states
- NPC, enemy, companion, and interaction systems
- Inventory and HUD support
- Level transitions and screen effects
- Lightweight Vite-based development workflow

## Tech Stack

- JavaScript (ES modules)
- HTML5 Canvas
- Vite
- Tiled map editor
- Aseprite sprite export workflow

## Project Goals

This project is meant to serve as both:

- a playable RPG prototype
- a reusable base for building more systems on top of the existing engine structure

The codebase is intentionally modular so features can be added without replacing the core architecture.
